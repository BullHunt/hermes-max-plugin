# Команды Hermes — справочник на русском

Это перевод того, что показывает команда `/commands` (полный список
команд шлюза Hermes, не только пункты меню MAX). Переведены только
**описания** — синтаксис самой команды (`/имя <аргументы>`) и алиасы
оставлены как есть: это литеральный текст, который должен совпадать с
тем, что реально распознаёт диспетчер команд Hermes
(`gateway/run.py`). Тот же принцип, что и с описаниями в меню MAX
(см. README, раздел «Localization») — переводим то, что не влияет на
разбор команды, и не трогаем то, что влияет.

Меню MAX (`/help`, `/commands`, `/status`, `/whoami`, `/model`, `/reset`,
`/new`, `/think`, `/verbose`, `/reasoning`, `/usage`, `/stop`) — это лишь
12 самых ходовых команд из списка ниже, ограниченных лимитом MAX в 32
пункта меню. Остальные всё равно работают, если написать их вручную.

## Сессии и история

| Команда | Описание |
| --- | --- |
| `/new [name]` (алиас: `/reset`) | Начать новую сессию (новый ID сессии + история) |
| `/resume [name]` | Возобновить ранее именованную сессию |
| `/sessions` | Просмотреть и возобновить предыдущие сессии |
| `/title [name]` | Задать заголовок текущей сессии |
| `/branch [name]` (алиас: `/fork`) | Создать ветку текущей сессии (исследовать другой путь) |
| `/retry` | Повторить последнее сообщение (переслать агенту) |
| `/undo [N]` | Откатить N реплик пользователя и переспросить (по умолчанию 1) |
| `/rollback [number]` | Показать список или восстановить контрольные точки файловой системы |
| `/compress [here [N] \| focus тема \| --preview\|--dry-run]` (алиас: `/compact`) | Сжать контекст разговора (`here [N]` — сохранить последние N реплик; `--preview` — показать, что произойдёт, не делая этого) |

## Выполнение и управление

| Команда | Описание |
| --- | --- |
| `/stop` | Остановить все запущенные фоновые процессы |
| `/approve [session\|always]` | Одобрить ожидающую опасную команду |
| `/deny [all] [причина]` | Отклонить ожидающую опасную команду (можно с указанием причины) |
| `/background <запрос>` (алиасы: `/bg`, `/btw`) | Выполнить запрос в фоне |
| `/agents` (алиас: `/tasks`) | Показать активных агентов и выполняемые задачи |
| `/queue <запрос>` (алиас: `/q`) | Поставить запрос в очередь на следующий ход (не прерывает текущий) |
| `/steer <запрос>` | Вставить сообщение после следующего вызова инструмента без прерывания |
| `/yolo` | Переключить режим YOLO (пропускать все подтверждения опасных команд) |

## Цели и автоматизация

| Команда | Описание |
| --- | --- |
| `/goal [текст \| draft <текст> \| show \| pause \| resume \| clear \| status \| wait <pid> \| unwait]` | Задать постоянную цель, над которой Hermes работает между репликами до достижения |
| `/subgoal [текст \| remove N \| clear]` | Добавить или управлять дополнительными критериями активной цели |
| `/moa <запрос>` | Прогнать один запрос через пресет Mixture of Agents по умолчанию, затем вернуть вашу модель |
| `/bundles` | Список наборов навыков (алиасы `/<имя>` для нескольких навыков сразу) |
| `/learn <что изучить>` | Выучить переиспользуемый навык из чего угодно (папки, ссылки, этот чат, заметки) |
| `/suggestions [accept\|dismiss N \| catalog]` (алиас: `/suggest`) | Просмотреть предложенные автоматизации (принять/отклонить) |
| `/blueprint [name] [slot=value ...]` (алиас: `/bp`) | Настроить автоматизацию по шаблону |
| `/curator [subcommand]` | Фоновое обслуживание навыков (статус, запуск, закрепить, архивировать, список архивных) |
| `/kanban [subcommand]` | Доска совместной работы для нескольких профилей (задачи, связи, комментарии) |

## Модель и поведение агента

| Команда | Описание |
| --- | --- |
| `/model [model] [--provider name] [--global\|--session] [--refresh]` | Сменить модель (по умолчанию сохраняется) |
| `/codex-runtime [auto\|codex_app_server]` | Переключить codex app-server runtime для моделей OpenAI/Codex |
| `/personality [name]` | Задать готовую личность/стиль общения |
| `/reasoning [level\|show\|hide\|full\|clamp]` | Управлять уровнем и отображением рассуждений |
| `/fast [normal\|fast\|status]` | Переключить быстрый режим — OpenAI Priority Processing / Anthropic Fast Mode |
| `/voice [on\|off\|tts\|status]` | Переключить голосовой режим |
| `/footer [on\|off\|status]` | Переключить подвал с служебными метаданными в финальных ответах |
| `/memory [pending\|approve\|reject\|approval] [id\|on\|off]` | Просмотреть ожидающие записи в память / переключить подтверждение записи |

## Статус и информация

| Команда | Описание |
| --- | --- |
| `/status` | Показать сессию, модель, токены и информацию о контексте |
| `/whoami` | Показать ваш уровень доступа к слэш-командам (admin / user) |
| `/profile` | Показать имя активного профиля и домашнюю директорию |
| `/usage [reset [--force]]` | Показать использование токенов и лимиты; `reset` списывает забронированный сброс лимита Codex |
| `/credits` | Показать баланс кредитов Nous и пополнить |
| `/insights [days]` | Показать аналитику использования |
| `/platform <pause\|resume\|list> [name]` | Приостановить, возобновить или показать список платформ шлюза с ошибками |
| `/version` (алиас: `/v`) | Показать версию Hermes Agent |
| `/debug [nous\|local]` | Загрузить отчёт для отладки (информация о системе + логи) и получить ссылки для отправки |

## Обслуживание и справка

| Команда | Описание |
| --- | --- |
| `/sethome` (алиас: `/set-home`) | Сделать этот чат домашним каналом |
| `/reload-mcp` | Перезагрузить MCP-серверы из конфига |
| `/reload-skills` | Пересканировать `~/.hermes/skills/` на новые или удалённые навыки |
| `/update` | Обновить Hermes Agent до последней версии |
| `/restart` | Плавно перезапустить шлюз после завершения активных запусков |
| `/commands [page]` | Просмотреть все команды и навыки (с постраничной навигацией) |
| `/help` | Показать доступные команды |
| `/start` | Подтверждает пинг запуска платформы без ответа (служебная, не для ручного вызова) |
| `/topic [off\|help\|session-id]` | Включить или посмотреть топик-сессии в личных сообщениях Telegram — на MAX неприменимо |
